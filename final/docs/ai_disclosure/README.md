# AI Disclosure Logs

This folder contains one AI-use log for each team member. Each log should document how AI assistance was used during the final project and how the resulting work was reviewed, verified, and modified by the team member.

## Suggested contents for each log

- Team member name
- Date or date range
- AI tool and model, when available
- Purpose of the assistance
- Files or project areas affected
- What was adopted, changed, or rejected
- How the work was reviewed and verified

The individual logs support the AI Use Acknowledgement section of the technical report. They do not replace the report's required acknowledgement and references.
